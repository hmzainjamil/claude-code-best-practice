# Security and product guidance

This repository documents an AI coding tool. Verify product and security recommendations against current official documentation before relying on them. Do not paste secrets or sensitive source code into a tool without confirming the active provider, data handling, and applicable organizational policy.

Before running any command or hook, inspect its source, permissions, network access, and effects. Use an isolated project for examples. This repository has not been security-audited as part of the README review.

Report vulnerabilities privately through GitHub reporting if enabled, or contact the repository maintainer through a private channel. Do not publish credentials or exploit details in public issues.
